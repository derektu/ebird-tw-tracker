# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-02

### Added

- Recent Taiwan eBird observation search by common name or species code.
- Interactive Leaflet map with synchronized observation list and markers.
- Background species tracking with configurable intervals and quiet hours.
- Notification history, native Electron notifications, and Menu Bar controls.
- API key configuration through environment variables or encrypted desktop settings.
- React, TypeScript, Vite, Node.js, and Electron application architecture.
- macOS DMG and Windows x64 NSIS build workflows.
