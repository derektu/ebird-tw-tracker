# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Do not include API keys, credentials, private observation data, or exploit details in a public issue.

Use GitHub private vulnerability reporting when it is enabled for this repository. If private reporting is unavailable, contact the repository owner privately before disclosing details publicly.

Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. Acknowledgement and remediation timelines depend on severity and reproducibility.
