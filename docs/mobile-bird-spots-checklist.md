# 在手機確認鳥點操作

這份清單供 #36 與 #38 的實機驗收使用。自動化結果見 [鳥點整體驗收紀錄](bird-spots-acceptance.md)。

## 開啟測試頁

1. 將手機連到與這台 Mac 相同的 Wi-Fi。
2. 在手機瀏覽器開啟 `https://192.168.81.98:7310/search`。這是本輪暫時測試網址，Mac 需要保持執行及連線。
3. 首次開啟時，瀏覽器會顯示測試用自簽憑證的警告。確認網址是上述區網位址，再從進階選項繼續。無需安裝憑證或設定描述檔。無法繼續時，記錄瀏覽器顯示的訊息。
4. 在 API key 畫面輸入自己的 eBird API key。不要把 key 放進回報或截圖。

手機使用獨立的 browser origin，桌面上輸入的 key 和收藏不會自動出現。後續測試保持使用同一網址與瀏覽器。這次取消了收藏匯入及匯出，沒有跨裝置搬移流程。

## 驗證操作

1. 展開搜尋條件，切換到「鳥點」，搜尋「清水濕地」。確認鍵盤開啟時可看到輸入位置，搜尋後摘要收合，地圖與結果清單沒有水平溢出。
2. 點鳥點名稱，確認詳情預設半屏。展開、收合、重開詳情，再捲動鳥種清單。確認返回、星號、展開與收合按鈕可點擊，底部手勢區沒有遮住內容。
3. 收藏這個鳥點，進入「我的鳥點」，開啟編輯。輸入別名及一段長筆記，捲到筆記底部。確認鍵盤開啟時能看清目前輸入內容，能捲動到需要的位置，儲存與取消可操作。
4. 收起鍵盤。確認頁面恢復正常高度，底部沒有多餘空白或被裁切的按鈕。旋轉為橫向，再轉回直向，確認瀏海及底部手勢區不遮住操作。
5. 儲存修改，再進入編輯，修改筆記後返回。依序試「繼續編輯」及「捨棄」。確認草稿與返回位置符合選擇。
6. 從我的鳥點進入詳情，再返回。確認收藏清單的搜尋、排序及位置保留。取消收藏後按復原，確認別名、筆記與釘選仍在。
7. 重新整理同一網址，再進入我的鳥點。確認收藏及已儲存內容仍在。

## 回報結果

回報手機型號、系統版本、瀏覽器名稱及版本，並逐項標示「通過」或問題步驟。若有問題，描述當時鍵盤是否開啟、直向或橫向、哪個按鈕被遮住。可附未包含 API key 的截圖。
